# Опис обсягу проекту (Scope Statement): DogLore

## 1. Що входить до обсягу проекту (In Scope)
Відповідно до вимог, у рамках проекту будуть реалізовані наступні функції:
* Розробка енциклопедичного модуля з каталогом порід собак та їхніми характеристиками (вага, зріст, характер, хвороби, догляд).
* Створення інтерактивного модуля (Особистого кабінету) для реєстрації профілю улюбленця.
* Реалізація функціоналу для ведення щоденника росту та ваги тварини.
* Додавання системи покрокового трекінгу успіхів у дресируванні.
* Впровадження можливості завантажувати фотографії та вести хронологію життя собаки.

## 2. Що виключається з обсягу проекту (Out of Scope)
Для забезпечення успішного завершення роботи в стислі терміни, наступні елементи не входять до поточного етапу:
* Розробка нативних мобільних додатків для iOS та Android (проект реалізується виключно як адаптивний веб-додаток).
* Пряма інтеграція з базами даних ветеринарних клінік, зоомагазинів або сервісів доставки.
* Внутрішні чати або месенджери для прямого спілкування між користувачами.
* Розширені системи штучного інтелекту для розпізнавання порід по фото або складної аналітики здоров'я.
