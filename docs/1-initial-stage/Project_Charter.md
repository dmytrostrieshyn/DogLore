# Хартія проекту (Project Charter): DogLore

## 1. Загальна інформація про проект
**Назва проекту:** Інтерактивна веб-платформа для власників собак "DogLore"
**Мета проекту:** Розробка веб-додатка, який поєднує в собі інформаційну базу даних порід собак та персоналізовану систему трекінгу для контролю за ростом, здоров'ям і дресируванням домашніх улюбленців.
**Актуальність:** Проект вирішує гостру потребу в зручних діджитал-інструментах для структурування процесу догляду за твариною в умовах активного розвитку культури відповідального ставлення до домашніх улюбленців ("пет-перентінг").

## 2. Основні цілі та завдання
* Створення енциклопедичного модуля з детальним каталогом порід собак та їхніми характеристиками.
* Реалізація інтерактивного модуля (Особистого кабінету) для створення профілів собак.
* Впровадження функціоналу ведення щоденника росту і ваги, а також трекінгу дресирування.
* Можливість завантажувати фотографії та вести хронологію життя собаки.

## 4. Ризики проекту
 **Технічні ризики:** Можливі баги при реєстрації користувачів або збереженні даних у профілях тварин.
 **Часові ризики:** Стислі терміни на реалізацію (1 робочий день на весь цикл від обговорення до деплою).
 **Ризики контенту:** Складність швидкого збору та структурування великого обсягу достовірної інформації про породи собак.
 **Організаційні ризики:** Необхідність безперервної координації зусиль 5 членів команди для зведення різних частин коду та дизайну в єдине ціле.

## 5. Критерії успіху проекту
* Наявність задеплоєного робочого веб-сайту з інтегрованою енциклопедією та системою реєстрації/авторизації.
* Коректна робота функціоналу створення профілю собаки та додавання записів (фото, трекінг).
* Підготовка та здача всієї необхідної супровідної проектної документації згідно із завданням.
