# План розподілу завдань (Task Assignment Plan)

## 1. Технологічний стек проекту
* **Frontend:** React.js, Tailwind CSS.
* **Backend / База даних / Автентифікація:** Firebase (Firestore, Firebase Auth).
* **Хостинг:** Firebase Hosting / Vercel.

## 2. Детальний розподіл завдань за ролями

### Стрієшин Дмитро (Team Lead / Lead Developer)
**Зона відповідальності:** Інфраструктура, архітектура та базова верстка.
* **Завдання:**
  1. Ініціалізація React-проекту та налаштування Tailwind CSS.
  2. Верстка сторінок "Енциклопедія" та "Картка породи" за допомогою Tailwind CSS.
  3. Створення проекту у Firebase та налаштування Firebase Auth (реєстрація/вхід).
  4. Налаштування роутингу (React Router) для переходів між розділами.
  5. Фінальний деплой MVP версії на хостинг.

### Бойко Богдан (Web Developer)
**Зона відповідальності:** Робота з даними та функціонал кабінетів.
* **Завдання:**
  1. Налаштування Firebase Firestore (структура бази даних, правила доступу).
  2. Розробка інтерфейсу "Особистий кабінет" (форми, завантаження фото).
  3. Написання логіки отримання та відображення даних про породи з Firestore.
  4. Імплементація CRUD-операцій для створення та редагування профілю собаки.

### Ледовських Ольга (UI/UX Designer)
**Зона відповідальності:** Дизайн-система та візуальний контроль.
* **Завдання:**
  1. Швидке прототипування інтерфейсів у Figma.
  2. Підбір палітри кольорів та шрифтів (адаптація під Tailwind).
  3. Підготовка графіки та іконок для сайту.
  4. Перевірка відповідності верстки макетам.

### Білоус Віктор (QA Engineer)
**Зона відповідальності:** Тестування та стабільність.
* **Завдання:**
  1. Перевірка логіки авторизації та захисту даних користувачів.
  2. Тестування функцій додавання/редагування даних у кабінеті.
  3. Перевірка адаптивності інтерфейсу на різних пристроях.
  4. Ведення журналу ризиків та фіксація знайдених помилок.

### Порохнавець Денис (Content Manager / Data Analyst)
**Зона відповідальності:** Контентна база та аналітика.
* **Завдання:**
  1. Підготовка структурованих даних про 20+ порід собак (JSON/CSV).
  2. Наповнення бази даних Firestore початковим контентом.
  3. Оптимізація зображень для швидкого завантаження сторінок.
  4. Підготовка демо-даних для профілів собак (пости, фото, метрики).

## 3. План синхронізації
* **Ранок:** Налаштування середовища, Firebase та верстка каркаса.
* **День:** Інтеграція БД Firestore до фронтенду, реалізація кабінетів.
* **Вечір:** Тестування, виправлення багів, наповнення контентом та деплой.
