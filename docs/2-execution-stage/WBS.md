# Work Breakdown Structure (WBS): DogLore

## 1. Ініціалізація та планування (Docs & Setup)
* 1.1. Створення репозиторію на GitHub та налаштування доступу.
* 1.2. Ініціалізація проекту (React + Vite + Tailwind CSS).
* 1.3. Написання проектної документації початкової стадії (Charter, Scope, RACI).

## 2. Дизайн та Контент (UI & Data)
* 2.1. Створення базових макетів (Wireframes) у Figma (Енциклопедія, Кабінет).
* 2.2. Підбір типографіки, кольорової палітри та іконок.
* 2.3. Збір текстової інформації та фотографій для мінімум 20 порід собак.
* 2.4. Форматування даних у формат JSON для зручного експорту.

## 3. Розробка (Development)
* 3.1. Налаштування Firebase (Створення проекту, ініціалізація Firestore та Auth).
* 3.2. Верстка загального каркаса додатку та налаштування React Router.
* 3.3. Розробка інтерфейсу та логіки модуля "Енциклопедія" (вивід списку порід).
* 3.4. Розробка модуля "Особистий кабінет" (форми реєстрації, додавання фото та параметрів собаки).
* 3.5. Інтеграція клієнтської частини з базою даних (CRUD операції).

## 4. Тестування та Деплой (QA & Release)
* 4.1. Тестування системи авторизації та валідації форм.
* 4.2. Перевірка адаптивності дизайну (мобільна та десктопна версії).
* 4.3. Виправлення знайдених критичних помилок (Bug fixing).
* 4.4. Деплой MVP версії проекту на хостинг.
* 4.5. Зведення всієї документації етапу виконання.
