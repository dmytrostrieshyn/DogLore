
# 🐾 DogLore: Інтерактивна веб-платформа для власників собак 

## 📌 Про проект
**DogLore** — це веб-додаток, який поєднує в собі інформаційну базу даних порід собак та персоналізовану систему трекінгу для контролю за ростом, здоров'ям і дресируванням домашніх улюбленців]. Проект розробляється в рамках розрахункової роботи з курсу "Управління ІТ-проектами".

Проект вирішує актуальну проблему сучасного "пет-перентінгу", надаючи користувачам єдину діджитал-платформу для отримання перевіреної інформації та структурування процесу догляду за твариною.

## 🚀 Основний функціонал

### 📖 Енциклопедичний модуль
Деталізований каталог порід собак із зазначенням їхніх ключових характеристик:
* Середня вага та зріст.
* Особливості характеру та схильність до хвороб.
* Вимоги до догляду.

### 🐶 Інтерактивний модуль (Особистий кабінет)
Можливість користувача створити профіль для свого улюбленця. Функціонал включає:
* Ведення щоденника росту та ваги.
* Покроковий трекінг успіхів у дресируванні.
* Можливість завантажувати фотографії та вести хронологію життя собаки.
